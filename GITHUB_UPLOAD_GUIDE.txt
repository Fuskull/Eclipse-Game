HOW TO UPLOAD ECLIPSE PROTOCOL TO GITHUB
=========================================

OPTION 1: USING GITHUB DESKTOP (EASIEST)
-----------------------------------------

1. INSTALL GITHUB DESKTOP:
   - Go to: https://desktop.github.com/
   - Download and install GitHub Desktop
   - Sign in with your GitHub account

2. CREATE REPOSITORY:
   - Open GitHub Desktop
   - Click "File" → "New Repository"
   - Name: eclipse-protocol
   - Description: "Top-down action game with LÖVE"
   - Local Path: Choose the folder containing EclipseProtocol
   - Click "Create Repository"

3. ADD FILES:
   - GitHub Desktop will automatically detect all files
   - Review the files in the "Changes" tab
   - Make sure EclipseProtocol folder is included

4. COMMIT:
   - Write commit message: "Initial commit - Eclipse Protocol game"
   - Click "Commit to main"

5. PUBLISH:
   - Click "Publish repository"
   - Choose "Public" or "Private"
   - Click "Publish Repository"

6. DONE!
   - Your game is now on GitHub
   - Visit: https://github.com/YOUR_USERNAME/eclipse-protocol


OPTION 2: USING GIT COMMAND LINE
---------------------------------

1. INSTALL GIT:
   - Windows: https://git-scm.com/download/win
   - Run installer with default settings

2. OPEN TERMINAL:
   - Open PowerShell or Command Prompt
   - Navigate to your project folder:
     cd "C:\Users\Abdelrahman\Downloads\New folder (3)"

3. INITIALIZE GIT:
   git init

4. ADD FILES:
   git add EclipseProtocol/
   git add .gitignore
   git add GITHUB_UPLOAD_GUIDE.txt

5. COMMIT:
   git commit -m "Initial commit - Eclipse Protocol game"

6. CREATE GITHUB REPOSITORY:
   - Go to: https://github.com/new
   - Repository name: eclipse-protocol
   - Description: "Top-down action game with LÖVE"
   - Choose Public or Private
   - DON'T initialize with README (we already have one)
   - Click "Create repository"

7. LINK AND PUSH:
   - Copy the commands from GitHub, they look like:
   
   git remote add origin https://github.com/YOUR_USERNAME/eclipse-protocol.git
   git branch -M main
   git push -u origin main

8. DONE!
   - Refresh your GitHub page
   - Your game is now uploaded


OPTION 3: USING VISUAL STUDIO CODE
-----------------------------------

1. OPEN PROJECT IN VS CODE:
   - File → Open Folder
   - Select the folder containing EclipseProtocol

2. INITIALIZE GIT:
   - Click Source Control icon (left sidebar)
   - Click "Initialize Repository"

3. STAGE FILES:
   - Click "+" next to "Changes" to stage all files
   - Or click "+" next to individual files

4. COMMIT:
   - Type commit message: "Initial commit - Eclipse Protocol game"
   - Click checkmark (✓) or press Ctrl+Enter

5. CREATE GITHUB REPOSITORY:
   - Go to: https://github.com/new
   - Repository name: eclipse-protocol
   - Click "Create repository"

6. PUBLISH:
   - In VS Code, click "Publish Branch"
   - Sign in to GitHub if prompted
   - Choose repository name
   - Choose Public or Private
   - Click "Publish"

7. DONE!

3. SHARE YOUR GAME:

UPDATING YOUR GAME LATER:
-------------------------

When you make changes and want to upload them:

GITHUB DESKTOP:
1. Open GitHub Desktop
2. It will show your changes
3. Write commit message
4. Click "Commit to main"
5. Click "Push origin"

COMMAND LINE:
git add .
git commit -m "Description of changes"
git push

VS CODE:
1. Click Source Control
2. Stage changes (click +)
3. Write commit message
4. Click checkmark
5. Click "Sync Changes"


TROUBLESHOOTING:
---------------

Q: "Git is not recognized"
A: Install Git from https://git-scm.com/

Q: "Permission denied"
A: Set up SSH key or use HTTPS with personal access token

Q: "Files too large"
A: GitHub has 100MB file limit. Check your assets folder.

Q: "Repository already exists"
A: Use a different name or delete the old repository

Q: "Authentication failed"
A: Sign in to GitHub in your tool (Desktop/VS Code)

DEVELOPER MODE - LEVEL CREATOR GUIDE
====================================

HOW TO ACCESS:
-------------
1. Start the game
2. At main menu, press D for Developer Mode
3. Level creator opens


WHAT YOU CAN DO:
---------------
✓ Place walls anywhere
✓ Place patrol enemies
✓ Place hunter enemies
✓ Set spawn point (where player starts)
✓ Set exit door location
✓ Erase placed objects
✓ Save and load custom levels
✓ Test your level instantly


CONTROLS:
--------
LEFT CLICK - Place selected tool
TAB - Switch between tools
ARROW KEYS - Move camera around
ESC - Back to menu

QUICK TOOL SELECTION:
1 - Wall tool
2 - Enemy tool (patrol)
3 - Hunter tool (AI enemy)
4 - Spawn point tool
5 - Exit door tool
6 - Erase tool

OTHER KEYS:
G - Toggle grid snap on/off
H - Toggle help panel
T - Test level (play your custom level)
S - Save level to file
L - Load level from file
C - Clear all (delete everything)


TOOLS EXPLAINED:
---------------

1. WALL TOOL:
   - Click to place walls
   - Walls block player and enemies
   - Snap to grid for clean placement
   - Use for cover and obstacles

2. ENEMY TOOL (Patrol):
   - Click to place patrol enemies
   - Red squares with "E" label
   - They patrol back and forth
   - Deal damage on contact

3. HUNTER TOOL (AI):
   - Click to place hunter enemies
   - Orange squares with "H" label
   - They chase the player
   - More dangerous than patrols

4. SPAWN POINT:
   - Green circle marked "SPAWN"
   - Where player starts the level
   - Only one spawn point
   - Click to move it

5. EXIT DOOR:
   - Green rectangle marked "EXIT"
   - Level goal - reach this to win
   - Only one exit door
   - Click to move it

6. ERASE TOOL:
   - Click on objects to delete them
   - Works on walls, enemies, hunters
   - Cannot erase spawn or exit


LEVEL DESIGN TIPS:
-----------------
- Start simple with a few walls and enemies
- Test frequently (press T)
- Make sure spawn point is safe
- Don't block the exit door completely
- Use walls for cover from enemies
- Mix patrol and hunter enemies for variety
- Leave space for player to move


SAVING & LOADING:
----------------
SAVE: Press S
- Saves to "custom_level.lua"
- Located in game save directory
- Overwrites previous save

LOAD: Press L
- Loads "custom_level.lua"
- Restores all walls and enemies
- If file not found, shows error

TEST: Press T
- Instantly play your level
- All features work (weapons, dash, etc.)
- Press ESC to return to editor


GRID SYSTEM:
-----------
- Grid size: 40x40 pixels
- Press G to toggle grid snap
- Grid ON: Objects snap to grid (clean placement)
- Grid OFF: Free placement anywhere
- Grid lines visible when enabled


CAMERA MOVEMENT:
---------------
- Use ARROW KEYS to pan camera
- Useful for large levels
- Camera speed: 300 pixels/second
- No zoom (fixed view)


UI OVERLAY:
----------
TOP BAR shows:
- Current tool name
- Number of walls placed
- Number of enemies placed
- Number of hunters placed

HELP PANEL (press H):
- Shows all controls
- Shows tool list
- Toggle on/off for more space


TECHNICAL INFO:
--------------
Room size: 800x600 pixels
Grid size: 40x40 pixels
Max objects: Unlimited
File format: Lua table
Save location: Love2D save directory


TROUBLESHOOTING:
---------------
Q: Objects not placing?
A: Make sure you're clicking in the room area

Q: Can't see my objects?
A: Use arrow keys to move camera

Q: Test level crashes?
A: Make sure spawn point is not inside a wall

Q: Save/Load not working?
A: Check console for error messages


EXAMPLE WORKFLOW:
----------------
1. Press D at menu to enter developer mode
2. Press 1 to select wall tool
3. Click to place walls around the edges
4. Press 2 to select enemy tool
5. Click to place a few enemies
6. Press 3 to select hunter tool
7. Click to place a hunter
8. Press 4 and click to set spawn point
9. Press 5 and click to set exit door
10. Press T to test your level
11. Press S to save when satisfied

📊 XP & LEVELING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

HOW IT WORKS:
- Kill enemies to gain XP
- XP bar shown at top (blue bar)
- Level up when bar fills
- Each level requires 50% more XP
- Level 1→2: 100 XP
- Level 2→3: 150 XP
- Level 3→4: 225 XP
- And so on...

XP REWARDS:
- Patrol Enemy: 15 XP
- Hunter Enemy: 25 XP

🔫 AMMO SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STARTING AMMO: 100
MAX AMMO: 100 (upgradeable)

AMMO USAGE:
- Melee: No ammo needed
- Gun: 1 ammo per shot
- Multi-Shot: Still 1 ammo (fires multiple bullets!)

AMMO DISPLAY:
- Shows "Ammo: 85/100" when using gun
- Turns red when low (< 20)
- Can't shoot with 0 ammo

REFILLING AMMO:
- Pick up yellow ammo packs (+30)
- Upgrade ammo capacity
- Switch to melee when out

💡 STRATEGY TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

EARLY GAME (Levels 1-3):
- Focus on Max Health upgrades
- Collect all pickups
- Use gun to stay safe
- Save ammo for hunters

MID GAME (Levels 4-6):
- Get Multi-Shot (game changer!)
- Health Regen is very strong
- Ammo Capacity if using gun a lot
- Faster Cooldowns for DPS

LATE GAME (Levels 7+):
- Stack Move Speed for dodging
- Energy Regen for mobility
- More Multi-Shot bullets
- Health Regen keeps you alive

BEST UPGRADE COMBOS:
1. Multi-Shot + Faster Cooldowns = Bullet storm
2. Health Regen + Max Health = Tank build
3. Move Speed + Dash Distance = Speed demon
4. Ammo Capacity + Multi-Shot = Never reload

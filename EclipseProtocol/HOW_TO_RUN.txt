║         HOW TO RUN ECLIPSE PROTOCOL                       ║
╚═══════════════════════════════════════════════════════════╝

📥 STEP 1: INSTALL LOVE2D
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Go to: https://love2d.org/
2. Download Love2D for Windows
3. Install it (default location: C:\Program Files\LOVE\)

🎮 STEP 2: RUN THE GAME (Choose ONE method)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD 1 (Easiest):
   → Drag the "EclipseProtocol" folder onto love.exe

METHOD 2 (Batch File):
   → Double-click "RUN_GAME.bat" in this folder

METHOD 3 (Command Line):
   → Open terminal in parent folder
   → Run: love EclipseProtocol

METHOD 4 (Direct Path):
   → Open terminal in this folder
   → Run: "C:\Program Files\LOVE\love.exe" .

✅ VERIFY IT'S WORKING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
You should see:
✓ Window opens (800x600)
✓ Blue square (player) on the left
✓ Red square (enemy) patrolling middle
✓ Health bar at top left
✓ Controls text displayed

🕹️ TEST THE GAME
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Press WASD or Arrow Keys → Player should move
2. Touch the red enemy → Health should decrease
3. Wait for health to reach 0 → "GAME OVER" appears

⚠️ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Problem: "Warning: hit.wav not found"
Solution: This is OK! Sound is optional. Game still works.

Problem: "No code to run"
Solution: Make sure you're running the EclipseProtocol FOLDER,
          not individual .lua files

Problem: Window opens then closes
Solution: Check console for error messages

📝 WHAT TO SUBMIT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Submit the entire "EclipseProtocol" folder containing:
✓ main.lua
✓ player.lua
✓ enemy.lua
✓ ui.lua
✓ conf.lua
✓ assets/ folder (even if empty)

Your professor can run it the same way!

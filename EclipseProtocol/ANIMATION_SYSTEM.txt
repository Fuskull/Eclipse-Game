ANIMATION SYSTEM - COMPLETE (ANIM8 VERSION)
============================================

DASH SYSTEM CHANGES:
-------------------
OLD: Dash was instant teleport (moved player.x/y by dashDistance)
NEW: Dash is smooth speed boost (increases speed to 500 for 0.3 seconds)

DASH MECHANICS:
- Normal speed: 200
- Dash speed: 500 (2.5x faster)
- Dash duration: 0.3 seconds
- Dash cost: 25 energy
- Dash cooldown: 1.0 seconds
- Visual effect: Blue glow trail during dash

UPGRADES:
- "Dash Speed +100" - increases dash speed by 100 and duration by 0.05s


SPRITE ANIMATION SYSTEM (ANIM8):
--------------------------------
LIBRARY: anim8 (kikito/anim8)
- Location: libraries/anim8.lua
- Automatically downloaded and integrated

SPRITE SHEETS:
1. player-sheet.png (melee/no gun)
2. player-sheet gun.png (with gun)

SPRITE SHEET LAYOUT:
Each sheet is a 4x4 grid with 12x18 pixel sprites:
- Row 1: Down animation (4 frames)
- Row 2: Left animation (4 frames)
- Row 3: Right animation (4 frames)
- Row 4: Up animation (4 frames)

ANIMATION BEHAVIOR:
- Frame 2: Idle pose (shown when not moving)
- Frames 1-4: Walking cycle (loops when moving)
- Animation speed: 0.2 seconds per frame
- Direction changes based on last key pressed
- Automatically switches between melee/gun sprites when weapon changes

WEAPON-BASED ANIMATIONS:
- When weapon = MELEE: Uses player-sheet.png
- When weapon = GUN: Uses player-sheet gun.png
- Seamless switching when pressing Q
- Same animation structure for both sheets


HOW TO CUSTOMIZE YOUR SPRITE SHEETS:
------------------------------------
1. Each sprite should be 12x18 pixels
2. Layout in 4 rows (down, left, right, up)
3. 4 frames per row for walking animation
4. Frame 2 is the idle/standing pose
5. Both sheets must have identical layout

ADJUSTING SPRITE SIZE:
If your sprites are different size, edit player.lua:
- player.spriteWidth = 12  -- change to your sprite width
- player.spriteHeight = 18  -- change to your sprite height

SCALING:
- Sprites are scaled 3.5x for visibility (12x18 → 42x63 on screen)
- Adjust scale in player.draw() if needed

FALLBACK:
If sprite sheets or anim8 fail to load, the game will use
the original blue rectangle as a fallback.


VISUAL EFFECTS:
--------------
DASH EFFECT:
- Semi-transparent sprite during dash (0.7 opacity)
- Blue circular glow around player
- Trail effect visible during dash

WEAPON SWITCHING:
- Instant sprite sheet swap when pressing Q
- No animation interruption
- Maintains current direction and frame


CONTROLS:
--------
WASD / Arrow Keys: Move (changes animation direction)
Shift: Dash (smooth speed boost with visual effect)
Q: Switch weapon (changes sprite sheet)
R: Reload gun
Left Click: Attack
1/2/3: Select upgrade (when level up menu shows)
ESC: Pause


TECHNICAL DETAILS:
-----------------
ANIM8 INTEGRATION:
- Grid system: anim8.newGrid(12, 18, width, height)
- Animation creation: anim8.newAnimation(grid('1-4', row), 0.2)
- Update: animation:update(dt)
- Draw: animation:draw(spriteSheet, x, y, rotation, scaleX, scaleY, originX, originY)
- Idle: animation:gotoFrame(2)

PERFORMANCE:
- Both sprite sheets loaded once at player.load()
- Animations pre-created (no runtime generation)
- Only active animation updates each frame
- Minimal overhead from weapon switching


FILES REQUIRED:
--------------
- libraries/anim8.lua (animation library)
- assets/images/player-sheet.png (melee sprites)
- assets/images/player-sheet gun.png (gun sprites)


ADDING ENEMY ANIMATIONS:
------------------------
To add anim8 animations to enemies:
1. Create enemy sprite sheets (same 4x4 layout)
2. Load anim8 in enemy.lua
3. Create grids and animations
4. Update animation in enemy.updateAll()
5. Draw with animation:draw() in enemy.drawAll()

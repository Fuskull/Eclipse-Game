🔫 MAGAZINE & RELOAD SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

HOW IT WORKS:
┌─────────────────────────────────────────────────────────┐
│ Magazine Size: 5 bullets                                │
│ Reload Time: 1.5 seconds                                │
│ Reserve Ammo: 100 bullets                               │
│ Control: Press R to reload                              │
└─────────────────────────────────────────────────────────┘

MAGAZINE SYSTEM:
1. Start with 5 bullets in magazine
2. Each shot uses 1 bullet from magazine
3. After 5 shots, magazine is empty
4. Press R to reload (takes 1.5 seconds)
5. Reloading takes bullets from reserve ammo
6. Can't shoot while reloading!

AUTO-RELOAD:
- If you try to shoot with empty magazine
- Automatically starts reloading
- Or press R manually anytime

UI DISPLAY:
┌─────────────────────────────────────────────────────────┐
│ Normal:                                                  │
│ Mag: 5/5                                                │
│ Ammo: 100                                               │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ After 3 shots:                                          │
│ Mag: 2/5                                                │
│ Ammo: 100                                               │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ Empty magazine:                                         │
│ Mag: 0/5 (RED)                                          │
│ Ammo: 100                                               │
│ Press R to reload!                                      │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ Reloading:                                              │
│ RELOADING... 1.2 (ORANGE)                               │
└─────────────────────────────────────────────────────────┘

STRATEGIC DEPTH:
✓ Must manage magazine carefully
✓ Reload during safe moments
✓ Can't spam bullets anymore
✓ Switch to melee while reloading
✓ More tactical gameplay

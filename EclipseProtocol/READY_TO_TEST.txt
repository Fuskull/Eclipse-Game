HOW TO RUN:
----------
1. Open terminal in project folder
2. Run: love EclipseProtocol
   OR
3. Double-click: RUN_GAME.bat


CONTROLS:
--------
WASD / Arrow Keys - Move (animated walking)
Shift - Dash (smooth speed boost)
Q - Switch weapon (changes sprite)
R - Reload gun
Left Click - Attack
1/2/3 - Select upgrade
ESC - Pause

TROUBLESHOOTING:
---------------
If sprites don't show:
→ Check console for warnings
→ Verify sprite files in assets/images/
→ Game will use blue rectangle as fallback

If animations don't play:
→ Check anim8.lua in libraries/
→ Verify sprite sheet format (4x4 grid)

If weapon switching doesn't work:
→ Press Q to switch
→ Check both sprite sheets loaded

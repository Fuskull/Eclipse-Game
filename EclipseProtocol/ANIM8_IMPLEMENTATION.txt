SPRITE SHEET SPECIFICATIONS:
---------------------------
Format: 4 rows x 4 columns
Sprite size: 12x18 pixels per frame
Total size: 48x72 pixels

Layout:
- Row 1: Down walking (4 frames)
- Row 2: Left walking (4 frames)
- Row 3: Right walking (4 frames)
- Row 4: Up walking (4 frames)

Frame 2 in each row = idle/standing pose


HOW IT WORKS:
------------

1. INITIALIZATION (player.load):
   - Load anim8 library
   - Load both sprite sheets
   - Create grids for each sheet (12x18 pixels)
   - Create 4 animations per sheet (down, left, right, up)
   - Set initial animation to melee down

2. UPDATE (player.update):
   - Detect movement direction
   - Choose animation set (melee or gun)
   - Select direction animation
   - If moving: update animation (cycles frames)
   - If idle: go to frame 2 (standing pose)

3. DRAW (player.draw):
   - Determine which sprite sheet to use
   - Draw current animation with anim8
   - Apply scaling (3.5x)
   - Add dash effects if dashing
   - Fallback to rectangle if sprites missing


WEAPON SWITCHING LOGIC:
-----------------------
When player presses Q:
1. weapons.switchWeapon() changes weapons.currentWeapon
2. Next frame, player.update() checks weapons.currentWeapon
3. If MELEE: uses player.animationsMelee
4. If GUN: uses player.animationsGun
5. Sprite sheet changes in player.draw()
6. Animation continues from current frame

TROUBLESHOOTING:
---------------

If sprites don't show:
1. Check console for "Warning: player-sheet.png not found"
2. Verify files exist in assets/images/
3. Check file names match exactly (case sensitive)
4. Game will use blue rectangle as fallback

If animations don't play:
1. Check console for "Warning: anim8 library not found"
2. Verify libraries/anim8.lua exists
3. Try re-downloading anim8.lua

If weapon switching doesn't work:
1. Make sure both sprite sheets loaded successfully
2. Check weapons.lua has MELEE and GUN constants
3. Verify Q key switches weapons

✓ Test levels instantly
✓ Visual feedback and help panel


HOW TO USE:
----------
1. Start game
2. At main menu, press D
3. Use tools to build your level:
   - TAB to switch tools
   - LEFT CLICK to place
   - Number keys (1-6) for quick tool select
4. Press T to test your level
5. Press S to save
6. Press ESC to return to menu


TOOLS AVAILABLE:
---------------
1. Wall - Place obstacles and cover
2. Enemy - Place patrol enemies (red)
3. Hunter - Place AI enemies (orange)
4. Spawn - Set player start position (green)
5. Exit - Set level goal door (green)
6. Erase - Remove placed objects

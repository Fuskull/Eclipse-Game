Implementation in hunter.lua:
- STATE_IDLE: Waiting
- STATE_PATROL: Moving between points
- STATE_CHASE: Pursuing player
- STATE_RETURN: Going back to spawn

State Transitions:
- Patrol → Chase (player in range)
- Chase → Return (player escaped)
- Return → Patrol (reached spawn)
